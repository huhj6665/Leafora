审查日期：2026-10-02。本次整理针对当前工作副本，不修改原项目备份，不提交或推送 Git。

## 整理范围

- 将真实环境配置、设备凭据、私人开发工具配置移出源码。
- 将数据库、用户图片、配对产物、运行日志、离线缓存和本地服务状态移入项目外的私人备份。
- 将开发窗口提示词、协作记录、交接报告、设计试稿和生成的预览产物移出源码；保留农业助手实际运行需要的系统提示及业务测试。
- 将虚拟环境、依赖目录、构建产物、Python 缓存及模型权重移入私人备份；保留依赖清单、锁文件、模型加载代码和配置模板。
- 小程序公开配置改为 `touristappid`；测试账号改为合成数据。数据维护脚本不再内置个人手机号，需要显式传入 `--phone`。
- 阿里云短信签名与模板默认留空；关闭默认调试，生产环境拒绝空白或默认 JWT 密钥。实际部署仍需自行提供安全配置。
- 演示烟田底图迁移到 `assets/`，更新引用和安装步骤。保留页面实际使用的素材。
- 补充项目说明、安全说明、部署步骤、素材说明、GitHub 上传指南和只读审查工具。

所有移出的材料均可从项目外的私人备份恢复。备份可能包含有效凭据和个人数据，不应上传、分享或直接复制回公开仓库。

## Git 历史边界

开发目录的 `.git` 原样保留；没有改写历史、强制回滚、暂存、提交或推送。旧历史可能包含敏感内容，因此不能把它当作已清理历史上传。

`Leafora2-GitHub/` 是仅复制当前可发布文件的独立副本，不包含 `.git` 或私人备份。首次发布在该目录新建 Git 仓库，只提交新的源码快照。
